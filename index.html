Atalhos de Teclado

  • Ctrl+Z - Desfazer
  • Ctrl+Y - Refazer
  • Ctrl+C - Copiar
  • Ctrl+V - Colar
  • Ctrl+X - Recortar
  • Ctrl+B/I/U - Negrito/Itálico/Sublinhado
  • Ctrl+F - Localizar e substituir
  • F2 - Editar célula
  • Delete - Limpar célula
  • Ctrl+Home - Ir para A1
  • Ctrl+End - Ir para última célula
  • Shift+Setas - Estender seleção
  • Ctrl+Setas - Ir até o limite dos dados
  • Tab / Enter - Mover para direita / abaixo

Categorias de Fórmulas Disponíveis

  • Matemática: SUM, PRODUCT, ROUND, ABS, SQRT, POWER, MOD, INT, TRUNC, PI, RAND, RANDBETWEEN…
  • Estatística: AVERAGE, MEDIAN, MAX, MIN, COUNT, COUNTA, COUNTBLANK, STDEV, VAR, RANK, LARGE, SMALL…
  • Lógica: IF, AND, OR, NOT, IFERROR, ISERROR, ISBLANK, ISNUMBER, ISTEXT…
  • Texto: CONCATENATE, LEFT, RIGHT, MID, LEN, UPPER, LOWER, PROPER, TRIM, SUBSTITUTE, FIND, TEXT…
  • Pesquisa: VLOOKUP, HLOOKUP, INDEX, MATCH, CHOOSE…
  • Data/Hora: TODAY, NOW, DATE, YEAR, MONTH, DAY…
  • Condicionais: SUMIF, COUNTIF, SUMIFS, COUNTIFS…

Use o botão fx na barra de fórmulas ou a aba Fórmulas para ver a lista completa.
