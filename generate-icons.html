📁 Instruções de Instalação

  1. Crie uma pasta chamada icons na raiz do projeto
  2. Baixe todos os ícones ou individualmente
  3. Coloque todos os arquivos .png na pasta icons/
  4. O arquivo manifest.json já está configurado para usar esses ícones
  5. Instale o PWA clicando no ícone de instalação no navegador
